# 初始开发计划

> 历史资料：这些阶段已基本完成。当前能力以 [功能清单](features.md) 和代码为准。

## 阶段 0：工程初始化

- 建立 monorepo 目录结构。
- 完成 Docker Compose、数据库扩展、环境变量模板。
- 建立 Spring Boot 和 Flutter Web 项目骨架。

## 阶段 1：后端基础设施

- 接入 PostgreSQL、Flyway、Redis、MinIO。
- 实现统一响应、异常处理、参数校验。
- 实现邮箱注册登录、JWT、GitHub OAuth。
- 建立角色权限和管理员路由保护。

## 阶段 2：内容闭环

- 实现内容、标签、媒体、朋友 CRUD。
- 实现公开推荐、搜索、详情接口。
- Flutter 完成首页、列表、详情、朋友页。

## 阶段 3：互动闭环

- 实现评论、点赞、浏览记录。
- 实现用户中心的资料维护和记录管理。
- 增加互动统计回写和分页查询。

## 阶段 4：AI 闭环

- 接入 OpenAI 兼容 Chat/Embedding。
- 使用 pgvector 建立知识库切片和检索。
- 实现每日 10 次提问配额。
- 暴露 AI 工具调用：搜索、详情、评论、点赞、取消点赞、删除评论。

## 阶段 5：管理员后台

- 完成统计控制台、日志监控。
- 完成用户、内容、媒体、标签、朋友、互动记录、AI 记录、知识库管理。
- 增加审计日志。

## 阶段 6：上线准备

- 补充单元测试、集成测试、Flutter widget test。
- 完善生产配置、CORS、安全头、限流、备份策略。
- 输出部署说明和回滚流程。
