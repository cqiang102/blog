# 人工测试用例

> 适用于 `1.0.0` 发布前人工验收。本文档面向本地 IDE 调试流程：`scripts/infra.sh` 启动依赖，IDE 运行后端，Flutter/IDE 运行前端。

## 测试范围

优先级说明：

- `P0`：发布阻塞项，必须通过。
- `P1`：核心功能，建议本轮通过。
- `P2`：增强体验或边界场景，可按时间抽测。

结果标记：

- `[ ]` 未测
- `[x]` 通过
- `[!]` 有问题，记录现象、接口、截图或日志
- `[-]` 本轮跳过，注明原因

## 环境准备

### 本地依赖

```bash
scripts/infra.sh up
scripts/infra.sh status
```

确认：

- PostgreSQL：`localhost:5432`
- Redis：`localhost:6379`
- MinIO API：`localhost:9000`
- MinIO Console：`localhost:9001`
- 本地数据目录：`deploy/.data/`

如果需要重置本地数据：

```bash
scripts/infra.sh reset
```

### 后端

用 IDE 运行 `apps/api`，建议配置：

- Spring profile：`dev`
- env file：`apps/api/.env`
- API 地址：`http://localhost:8080`

启动后检查：

```bash
curl http://localhost:8080/actuator/health/liveness
curl http://localhost:8080/actuator/health/readiness
curl http://localhost:8080/api/v1/meta
```

### 前端

```bash
cd apps/web_flutter
fvm flutter pub get
fvm flutter run -d chrome
```

建议测试视口：

- 桌面：1440 x 900
- 平板：768 x 1024
- 手机：390 x 844

### 测试账号

| 角色 | 准备方式 |
|------|----------|
| 管理员 | 使用 `apps/api/.env` 中的 `ADMIN_EMAIL` / `ADMIN_PASSWORD` |
| 普通用户 | 前端注册新邮箱，或用管理员后台创建/调整 |
| GitHub 用户 | 需要 `GITHUB_CLIENT_ID` 和 `GITHUB_CLIENT_SECRET` 已配置 |

不要把真实密码写入测试记录。
